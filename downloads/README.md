# Try the mod

Download `ae2-storage-categories-0.5.0-prototype.jar` and place it in your Minecraft instance's `mods` folder while the game is closed. Do not extract the JAR. Remove any older version of this mod first.

Required: Minecraft 1.21.1, NeoForge 21.1.248 and Applied Energistics 2 19.2.17. Wireless support targets AE2WTLib 19.5.1.

Start with a test world. Connect an ME Category Controller to a powered ME network, insert configured View Cells, name the category and open your terminal. Click category headers to collapse them; F8 toggles the grouped view.

This is experimental version 0.5.0. Multiplayer requires installation on the server and clients; testing has focused on single-player.

Only our mod is included. Minecraft, NeoForge and AE2 must be installed separately. SHA256SUMS.txt contains the checksum of the supplied JAR.
